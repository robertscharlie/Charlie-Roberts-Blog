A small collection of games built with Pygame while learning Python and game development — each one started as a way to practice a different concept: sprite groups, collision detection, grid-based logic, and simple physics.

**Ballz** — a brick-breaker inspired by the mobile game *Ballz*. Click to aim and fire a stream of balls at descending numbered blocks; each hit knocks a block's number down, and it's destroyed at zero. Catch coins mid-flight for extra balls on the next shot. Miss too many blocks and it's game over.

**Tetris** — a classic falling-block puzzle game built from scratch, including piece rotation and full-row clearing.

**Stack:** Python, Pygame
